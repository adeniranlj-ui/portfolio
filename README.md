# Portfolio

Personal portfolio site for Lj Adeniran, Computer Information Systems student at Texas State University.

**Live site:** https://adeniranlj-ui.github.io/portfolio/

## Features
- Three pages (Home, Projects, Contact) with a shared navigation bar
- Responsive, mobile-first layout using Flexbox and CSS Grid
- **Dark mode toggle** that follows your system setting on the first visit and remembers your choice
- Embedded contact form

## Built with
HTML, CSS (custom properties, Flexbox, Grid, media queries), and JavaScript
